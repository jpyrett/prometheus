Your new rule, as a contract (section 3). The Advisor sends a calculate_financials work order with a metrics list from a fixed catalogue (RSI, P/E, 12-1 momentum, ATR, ADV, beta, net payout yield, SUE, …). The Data Clerk computes each in plain Python from the stored day aggs, the Finnhub metrics payload and the filing evidence, and puts {value, as_of, window, source, inputs_summary, note} on data.metrics. No model loop, no score words (the filing_signals test pattern). The desk becomes advisor_plan -> data_clerk_metrics -> advisor_score.
Seven strategies, each with the edge, the code rule, the text evidence it accepts, horizon, a literature prior, and failure modes that become Critic checks: post-earnings drift and guidance events; momentum with a quality filter and an explicit anti-chase rule (last-month winners reverse, so "on a run" is penalised, not rewarded); quality-on-sale reversal that only qualifies when the cause of the drop is classified non-fundamental; capital return (net payout yield, dilution as a counter-signal: this one is mostly built already via filing_signals.py); an event taxonomy with fixed directions and an underreaction test (a good event the price has not absorbed beats one that already gapped 15%); value with a value-trap guard; theme exposure for Case 2 that prefers the second-tier name with room over the crowded leader.
Scoring is all code: per-strategy score and confidence, expected return × confidence minus a volatility charge and a crowding penalty, conflicts resolved to the lower view (never summed), top-k by greedy MMR with sector/strategy caps, portfolio correlation and concentration penalties.
Gates, regime, sizing, exits: liquidity/freshness/red-flag/earnings-window gates; a SPY-derived regime that disables momentum after a drawdown rebound; ATR-based volatility sizing with the honest $1,000 "one share is oversized" flag; stop, target, time stop and machine-evaluable invalidation rules so the Critic's is_valid/is_expired/in_risk_level have something to read.
Schema v2 record (section 9): a table of what the Critic receives, who fills each section, and a test that the model only writes thesis/bull/bear/quotes, with every number in the thesis checked against the record.
Self-learning loop: an append-only ledger with 5/20/60-day outcomes from the bars, Brier calibration, strategy weights as Beta posteriors with shrinkage and a floor; thresholds deliberately not auto-tuned (too few samples).
Evaluation: walk-forward backtest with costs and T+1, three baselines including "buy the 1-month winners" (the system must beat that one or the anti-chase rule is wrong), ablations.
