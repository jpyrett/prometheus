# Test purge of 2026-11-15

The suite went from **4,511 tests to 2,774** (1,737 deleted, 39%) and from 2,876 test functions to 1,691. Jacob's instruction: *"The test suite is bloated with over 4400 tests. We need to purge any unneeded tests. Focus on keeping higher-level end to end tests and especially tests for more complex parts like the data collection, RAG, Trading, Account manager and recommendations."* The reasons and the method are design choices entry 90; this file is the record of what went.

**Nothing was lost that the rest of the suite does not already give**: the whole suite was run with a line tracer before and after, and the lines of `prometheus/` it executes are the same set (10,628 lines before, 10,628 after, none lost), with every line of the areas named above still run by at least four of the tests that stay. Every test that is left passes, except two that already failed and were left for Jacob (below). Everything deleted is in git (`git checkout HEAD -- tests/<file>` brings back a file; `git diff tests/` shows the functions).

## What was deleted, by reason

| Reason | Tests | How it was chosen |
|---|---|---|
| Redundant: every line they run is run by other tests that stay | 1,549 | a greedy pass over the traced test functions, least valuable first (a file with its own stand-in agent or model first, then the fewest lines); a function went only when every line it runs stayed covered by at least 4 other tests (data collection, RAG, trading, the Account Manager, recommendations), 3 (the Critic, the calendar and the clock, the RaiseFunds scenarios) or 1 (plumbing: the work order's validators, the profile's bounds, the ledger, the config files). The end-to-end and real-capture tests are never removed |
| Tools that are not the product: the model bake-off, the reliability battery, the lab's with-and-without table | 80 | `tests/test_compare_models.py`, `tests/test_agent_reliability.py`, `tests/test_advisor_with_without.py` (whole files; they ran no line of `prometheus/`) |
| Dead: never collected | 0 tests (7 functions) | `tests/fastmcp_quotes.py`: `pytest.ini` collects only `test_*.py` and `fastmcp_tools.py`, so its 7 tests, 2 of them marked skip for a Redis stub, never ran |
| Pinned the wording of a docstring, a module text, the folder layout or `.env.example` | 9 | they ran no product code and broke on rewording |
| The end-to-end script's prompt tests, the clones for press releases and filings and the spelling matrices | 99 | `tests/test_prometheus_script.py` keeps what protects the user: no paid call without a yes, nothing started on no input, every flag forwarded, the direct order, the help |

## What was NOT touched

- The 34 skipped tests are the paid live tests (`PROMETHEUS_LIVE_TESTS=1`): opt-in by design, not dead.
- The two tests that were already failing and are Jacob's to decide: `tests/test_rag_loaders.py::test_an_article_in_two_real_files_differs_only_in_its_tickers_or_a_corrected_time` (a real CVX article is stored with two times 7.8 hours apart; the purge had removed it as redundant and it was put back) and `tests/test_data_clerk_verification.py::test_recent_sources_respects_the_window_the_symbol_and_k` (it depends on the time of day: it passes only before 12:00 UTC).
- Never removed: the end-to-end and real-capture files (`test_end_to_end_live`, the session replays, the desk, the recommendations runner, `test_direct_order`, the handshake and the booking tests, the Critic's and the Advisor's real captures), and the guards that read source for a design invariant that AGENTS.md names.
- Left in place after the deletions, on purpose: helpers and imports that only a deleted test used (a later cleanup).
